# Triad Rugby Website

Starter static website for Triad Rugby.

## Stack

- HTML5
- Bootstrap 5.3.3
- Custom CSS
- Vanilla JavaScript
- Suitable for GitHub Pages

## Files

- `index.html` — site content and page structure
- `css/styles.css` — Triad Rugby red/white/blue theme and accessibility styling
- `js/script.js` — small progressive-enhancement behaviors
- `assets/images/` — place team-owned images here later

## Accessibility choices included

- Semantic HTML landmarks (`header`, `nav`, `main`, `section`, `footer`)
- One primary `h1` and logical heading hierarchy
- Skip-to-content link
- Visible keyboard focus indicators
- Keyboard-friendly Bootstrap navigation
- Text labels instead of color-only meaning
- High-contrast red, white, and blue palette
- Responsive layout and text
- Reduced-motion preference support
- Descriptive link labels and ARIA labels where helpful
- No autoplaying or motion-heavy content
- Placeholder images are not represented as real images, avoiding missing-alt problems

## Before launch

Replace:

- Match details
- Practice location/time if needed
- Club email
- Instagram URL
- Facebook URL
- Sponsor names/logos
- Team and match photos
- Club history/about copy

## GitHub Pages

After committing these files to a GitHub repository, enable GitHub Pages in:

`Settings > Pages`

Then point the custom domain DNS records to GitHub Pages and add the domain in the Pages settings.

## Accessibility note

The starter is designed with WCAG-friendly practices, but accessibility should be re-tested after real images, links, embedded social content, sponsor logos, and other content are added.
